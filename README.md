# Ishq Toons reels
Faceless AI 3D cartoon couple dance reels (our own couple: Aarav + Meera) for YouTube Shorts, Instagram, Facebook.
- `prompts/` reel prompts (paste word for word into Google Flow, Veo 3.1 Lite, 9:16)
- `scripts/stitch.sh` joins 3 clips with crossfades (silent; song added from app music library at upload)
- `scripts/qa.sh` checks size, length, silence, black gaps, and makes a contact sheet
- `logs/credits.csv` every Flow credit spent. Never buy credits.
Rules: copy format only, never other creators' clips/characters. Tick AI/altered-content label on every upload. Every post scheduled, never live.
